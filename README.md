# ReyCars

Proyecto base para el sitio público y CMS administrativo de C.E.A. ReyCars.

## Stack
- Next.js
- React
- TypeScript
- CSS Modules
- Motion
- Firebase Authentication
- Cloud Firestore
- Firebase Storage

## Inicio
```bash
npm install
npm run dev
```

## Arquitectura
El sitio público y el administrador viven en el mismo proyecto, pero separados por route groups, módulos, layouts y componentes.
